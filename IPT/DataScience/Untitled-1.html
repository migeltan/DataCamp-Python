COMP 014 — Formula Cheat Sheet

Quantitative Methods with Modeling and Simulation

📊 Descriptive Statistics
Measures of Location
Arithmetic Mean
x̄ = Σx / n
Median
Middle value when sorted
Position = (n+1)/2
Mode
Most frequently occurring value
Measures of Spread
Range
Range = Max − Min
Interquartile Range
IQR = Q3 − Q1
Mean Absolute Deviation
MAD = Σ|x − x̄| / n
Variance
σ² = Σ(x − x̄)² / n
Standard Deviation
σ = √[Σ(x − x̄)² / n]
📈 Index Numbers
Simple Index
Index for period n
Iₙ = (Vₙ / V₀) × 100
Rebasing (new index)
New Index = Old Index × constant
constant = 100 / old index at new base period
Aggregate Indices
Simple Aggregate Index
= (ΣPₙ / ΣP₀) × 100
Mean Price Relative Index
= Σ(Pₙ/P₀ × 100) / number of items
Base-Weighted (Laspeyres)
= (ΣQ₀Pₙ / ΣQ₀P₀) × 100
Tends too HIGH — ignores substitution
Current-Weighted (Paasche)
= (ΣQₙPₙ / ΣQₙP₀) × 100
Tends too LOW — ignores past habits
Other Weighted Index
= (Σw × Pₙ/P₀) / Σw × 100
💰 Finance & Performance
Financial Ratios
Profit Margin
= (Profit before tax & interest / Sales) × 100
Return on Assets (ROA)
= (Net Profit + Interest + Tax) / Total Assets × 100
= EBIT / Total Assets × 100
Acid Test
= Liquid Assets / Liabilities
Productivity
= Output / Input (per unit of resource)
Break-Even Analysis
Revenue
R = N × P
Total Cost
TC = F + N×C
Break-Even Point
NP = F + NC → N* = F / (P − C)
Profit (above BEP)
Profit = N(P − C) − F
Loss (below BEP)
Loss = F − N(P − C)
VariableMeaning
NNumber of units
PPrice per unit
CVariable cost per unit
FFixed costs
P−CContribution per unit
Depreciation
Straight-Line Depreciation (annual)
D = (Cost − Scrap Value) / Useful Life
Fixed amount deducted each year
Reducing-Balance Depreciation
BVₙ = BV₀ × (1 − r)ⁿ
Fixed % of residual value each year
Time Value of Money
Future Value (Compound Interest)
FV = PV × (1 + r)ⁿ
Present Value (Discounting)
PV = FV / (1 + r)ⁿ
Net Present Value
NPV = Σ PV(revenues) − Σ PV(costs)
IRR = discount rate where NPV = 0
📉 Regression & Forecasting
Linear Regression
Line of Best Fit
y = a + bx
Slope (b)
b = (nΣxy − ΣxΣy) / (nΣx² − (Σx)²)
Intercept (a)
a = ȳ − b·x̄
Multiple Regression
y = a + b₁x₁ + b₂x₂ + ... + bₙxₙ
Correlation & Error
Coefficient of Determination
r² = Explained variation / Total variation
Closer to 1 = better fit
Spearman's Rank Correlation
rₛ = 1 − (6ΣD²) / (n(n²−1))
D = difference in rankings, n = pairs
Mean Squared Error
MSE = Σ(actual − forecast)² / n
Mean Absolute Error
MAE = Σ|actual − forecast| / n
Forecasting Methods
Simple Average
F = Σx / n
Moving Average (period n)
F = (x₁ + x₂ + ... + xₙ) / n
Uses only last n observations
Exponential Smoothing
Fₜ₊₁ = αXₜ + (1−α)Fₜ
α = smoothing constant (0.1–0.2 typical)
Seasonal Forecast (Multiplicative)
Forecast = Trend × Seasonal Index (S)
🎲 Probability & Distributions
Probability Rules
Independent Events (AND)
P(A and B) = P(A) × P(B)
Mutually Exclusive Events (OR)
P(A or B) = P(A) + P(B)
Conditional Probability
P(A|B) = P(A and B) / P(B)
Bayes' Theorem
P(A|B) = P(B|A)·P(A) / P(B)
Probability Distributions
Combinations (order doesn't matter)
ⁿCᵣ = n! / (r!(n−r)!)
Permutations (order matters)
ⁿPᵣ = n! / (n−r)!
Binomial — P(r successes in n trials)
P(r) = ⁿCᵣ × pʳ × (1−p)ⁿ⁻ʳ
Use when: 2 outcomes, fixed p, independent trials
Poisson — P(r events)
P(r) = e⁻λ × λʳ / r!
Use when: n large, p small, λ = np
Normal — Standardize
z = (x − μ) / σ
Then read from z-table
🔬 Sampling & Hypothesis Testing
Sampling
Standard Error of the Mean
SE = σ / √n
Bessel's Correction (small samples)
s = √[Σ(x−x̄)² / (n−1)]
Confidence Interval (mean)
x̄ ± z × (σ/√n)
Use t instead of z for small samples (n<30)
Confidence Interval (proportion)
p ± z × √[p(1−p)/n]
Hypothesis Testing
Test Statistic (z or t)
z = (x̄ − μ) / (σ/√n)
Use t-distribution when n < 30; df = n−1
Chi-Squared (goodness of fit)
χ² = Σ (O − E)² / E
df = (rows−1)(cols−1) for contingency table
Population Proportion SD
σₚ = √[p(1−p)/n]
🧠 Decision Making
Decision Criteria (No Probabilities)
Laplace (equally likely)
Choose max of row averages
Wald (maximin — pessimistic)
Choose best of worst outcomes per row
Savage (minimax regret)
Regret = Best in column − Actual outcome
→ Choose min of max regrets per row
Decision Making with Risk
Expected Value
EV = Σ P(outcome) × value
Decision Tree — Random Node
EV = Σ (probability × node value)
Decision Tree — Decision Node
Choose branch with highest EV
📦 Inventory Management
Economic Order Quantity (EOQ)
EOQ Formula
Q* = √(2DC / H)
D = annual demand, C = order cost, H = holding cost per unit/year
Cycle Length
T = Q* / D
Reorder Level (constant demand)
ROL = Lead Time × Daily Demand
Reorder Level (with safety stock)
ROL = Lead Time Demand + Safety Stock
🗂 Project Management (PERT/CPM)
Network Analysis
Earliest Finish Time
EFT = EST + Duration
Latest Start Time
LST = LFT − Duration
Total Float
Float = LST − EST (or LFT − EFT)
Float = 0 → Critical path activity
PERT (Rule of Sixths)
Expected Duration
te = (O + 4M + P) / 6
Variance of Duration
σ² = ((P − O) / 6)²
Project Mean & Variance
Sum te and σ² along critical path
O=optimistic, M=most likely, P=pessimistic
✅ Quality Control
Process Control (p-chart)
Mean Proportion Defective
p̄ = total defects / total inspected
Upper Control Limit (UCL)
UCL = p̄ + 3√[p̄(1−p̄)/n]
Lower Control Limit (LCL)
LCL = p̄ − 3√[p̄(1−p̄)/n]
Queuing Theory (Single Server)
Traffic Intensity (utilization)
ρ = λ / μ
λ = arrival rate, μ = service rate; must have ρ < 1
Mean Queue Length
Lq = ρ² / (1 − ρ)
Mean Time in System
W = 1 / (μ − λ)
